# DineOS website mark

The selected mark is the orange D with a fork inside. It is used in the shared
portal header, customer landing page, staff login page, favicon and Apple touch icon. The configurable
shop name and receipt logo are unchanged. No database or hosted settings changes
are needed.

Assets:

- `docs/branding/dineos-mark-master.png`: transparent generated master, retained for future export.
- `public/branding/dineos-mark.png`: 192 × 192 transparent header/login image.
- `public/branding/dineos-favicon.png`: 64 × 64 browser icon.
- `public/branding/dineos-touch-icon.png`: 180 × 180 home-screen icon.

Generated with the built-in image generation tool, then resized with macOS sips.
The original concept files are retained outside the project; runtime files all
live in the project and require no third-party image host.

## Final asset extraction prompt

Use case: background-extraction / logo-brand asset extraction. Edit target: the
attached approved DineOS logo. Extract ONLY its existing orange uppercase D-shaped
icon with the three-prong orange fork inside its transparent counter. Remove all
dark letters ineOS completely. Preserve the approved D and fork silhouette exactly,
do not redesign or add anything. Produce one centered isolated orange D/fork icon
on a genuinely transparent square canvas. Icon should occupy about 88% of the
canvas width with modest even safe margin, no stray pixels or remnants of letters.
Smooth clean edges, solid flat brand orange #F35A00 without gradients or texture,
transparent interior counter except the orange fork. Must remain readable as
uppercase D. No text, no white or colored background tile, no shadows, no other
symbols. This is a production website header logo and favicon asset.
